# Dual Vector Foil

A 31-second film that plays when the page opens: **https://xuedong-z.github.io/dual-vector-foil/**

A slip of light drifts between the stars. Its glow goes out, the plane opens, a ringed giant sinks into two
dimensions and spreads out as growth rings — and from the ice of Pluto, the Solar System hangs in the sky as a painting.

Every pixel and every sound is generated by code at load time: three full-screen ray-traced fragment shaders
(three.js r180 only as the WebGL wrapper), HDR bloom + ACES post, and a soundtrack synthesised with the Web Audio API.
No textures, no models, no samples, no build step.

- `src/shots.js` — the three shaders (foil, Saturn, Pluto)
- `src/timeline.js` — cameras and cuts
- `src/audio.js` — the score
- `?t=12` holds a moment, `?start=9` starts there, `?hq=1` renders 1920×1080

Run locally: `node tools/server.mjs` → http://localhost:5181

A fan homage to the dual-vector-foil scene in Liu Cixin's *Death's End*; not affiliated with any adaptation.
